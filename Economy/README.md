# Economy/ —— 仿真经济模块

## ✅ 已实现

### 阶段二：数据体系
- `Commodity.gd` — 城邦物资数据结构（ID/名称/品类/基准价/实时价/存量/产出消耗速率/稀缺波动率/热度系数/单日波动限制）+ 默认 6 类物资表
- `MarketBar.gd` — 经济行情数据（时间戳/开收盘/高低价/涨跌幅/成交量/挂单量/供需差值）
- `TradeOrder.gd` — 交易订单结构（求购/出售、成交状态、挂单主体、有效期）
- `PlayerData.gd` — 玩家（城主）数据（资金/库存/总资产/盈亏/治理记录/交互历史/市场习惯）
- `CityState.gd` — 城邦总状态容器（物资表+玩家+Agent+订单簿+行情历史，JSON 存档/读档）

### 阶段三：仿真经济算法
- `SupplyDemand.gd` — 供需驱动自治物价算法（供需差值/存量水平/成交量放大/均值回归）
- `MatchingEngine.gd` — 多主体智能撮合交易系统（价格优先、时间优先，AI↔AI / AI↔玩家）
- `EconomyEvent.gd` — 城邦随机事件系统（天灾减产/丰收增产/商队入驻/物资禁令/流行趋势/工坊升级）
- `EconomyEngine.gd` — 仿真主引擎（Autoload，SimulationLoop tick 驱动：产出消耗→挂单→撮合→物价→行情入库）
